# Библиотека фильтров изображений (Python, OpenCV, NumPy)

Практическая работа №1. Фильтры реализованы на базовых матричных операциях NumPy.
OpenCV используется только для чтения и кодирования файлов (`imdecode`, `imencode`).
Высокоуровневые функции (`resize`, `cvtColor`, `filter2D`, `Canny`, `GaussianBlur` и т. п.) не применяются.

## Структура проекта

| Файл | Назначение |
|---|---|
| `filters.py` | абстрактный класс `ImageFilter` (фабрика `get_filter`, метод `apply_filter`), классы фильтров, таблица `FILTERS` |
| `main.py` | `cli_argument_parser`, `read_image`, `save_image`, точка входа |
| `requirements.txt` | зависимости |

## Установка

```bash
python -m venv venv
venv\Scripts\activate        # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Положите изображения в папку `images`. Достаточно указать имя файла: программа найдёт его
в `images` и сохранит результат в папку `results` (создаётся автоматически).

```bash
python main.py -f <фильтр> -i <имя файла> [-o <имя результата>] [параметры]
```

- `-i cat.jpg` ищет файл сначала по указанному пути, затем в папке `images`.
- Без `-o` результат сохраняется как `results/<имя>_<фильтр>.png` (например, `results/cat_neon.png`).
- `-o name.png` сохраняет в `results/name.png`; если указан путь с папкой, используется он.

Примеры:

```bash
python main.py -f resize  -i cat.jpg -o cat_out.png --width 400 --height 300
python main.py -f resize  -i cat.jpg -o resize_half.png --scale 0.5 --method nearest
python main.py -f gray    -i cat.jpg -o gray.png
python main.py -f antique -i cat.jpg -o antique.png --intensity 0.9
python main.py -f fade    -i cat.jpg -o fade.png --alpha 0.5 --desaturation 0.6
python main.py -f film    -i cat.jpg -o film.png --grain 12 --contrast 1.3 --seed 1
python main.py -f matte   -i cat.jpg -o matte.png --radius 0.6 --feather 0.4
python main.py -f aged    -i cat.jpg -o aged.png --noise 14 --scratches 50 --dust 400
python main.py -f neon    -i cat.jpg -o neon.png --color 0 255 255 --glow_radius 8
```

При ошибке (нет файла, файл не изображение, неверные параметры) выводится сообщение
в поток ошибок и возвращается код 1.

### Фильтры и параметры

В скобках указаны значения по умолчанию.

| Фильтр (`-f`) | Класс | Параметры |
|---|---|---|
| `resize` | `Resize` | `--width`, `--height`, `--scale`, `--method` (bilinear или nearest; по умолчанию bilinear) |
| `gray` | `RGB2GrayScale` | нет |
| `antique` | `Antique` | `--intensity` от 0 до 1 (1) |
| `fade` | `FadeColor` | `--alpha` (0.4), `--desaturation` (0.5), `--level` (210) |
| `film` | `FilmEffect` | `--grain` (10), `--contrast` (1.2), `--seed` |
| `matte` | `Matte` | `--radius` (0.65), `--feather` (0.35) |
| `aged` | `AgedPhoto` | `--noise` (12), `--scratches` (40), `--dust` (300), `--seed` |
| `neon` | `Neon` | `--color R G B` (255 0 255), `--glow_radius` (6), `--glow_gain` (1.5), `--edge_threshold` (0.1) |

Для `resize` достаточно одного из `--width` / `--height` (пропорции сохраняются) или `--scale`.

## Математическое описание

Изображение это таблица пикселей. У каждого пикселя три числа от 0 до 255: B (синий),
G (зелёный), R (красный). Все расчёты ведутся в дробных числах. В конце результат округляется
и обрезается до диапазона 0..255: всё, что меньше 0, становится 0, всё, что больше 255, становится 255.

Обозначения: `W`, `H` ширина и высота изображения, `C` значение одного канала пикселя,
`clip(v, a, b)` обрезание числа `v` до диапазона от `a` до `b`.

### 1. Изменение разрешения (Resize)

Идея: для каждого пикселя нового изображения находим соответствующую точку в исходном
и берём цвет оттуда. `W_new`, `H_new` новые размеры.

```
x = (x_new + 0.5) * W / W_new - 0.5
y = (y_new + 0.5) * H / H_new - 0.5
```

Добавка 0.5 нужна, чтобы сопоставлять центры пикселей, а не их края. Точка (x, y) обычно
попадает между пикселями, поэтому есть два способа выбрать цвет.

**Ближайший сосед.** Берём цвет ближайшего пикселя:

```
результат = I(round(y), round(x))
```

**Билинейная интерполяция.** Берём четыре соседних пикселя и смешиваем их.
Чем ближе точка к пикселю, тем больше его вклад:

```
x0 = floor(x),  x1 = x0 + 1       (floor: округление вниз)
y0 = floor(y),  y1 = y0 + 1
dx = x - x0,    dy = y - y0       (числа от 0 до 1)

верх  = (1 - dx) * I(y0, x0) + dx * I(y0, x1)
низ   = (1 - dx) * I(y1, x0) + dx * I(y1, x1)

результат = (1 - dy) * верх + dy * низ
```

Координаты не выходят за границы изображения (x1 и y1 не больше последнего пикселя).

### 2. Оттенки серого (RGB2GrayScale)

Яркость пикселя это взвешенная сумма каналов. Веса отражают чувствительность глаза:
к зелёному он чувствителен сильнее всего, к синему слабее всего.

```
Y = 0.299 * R + 0.587 * G + 0.114 * B
```

Значение Y записывается в результат как одно число на пиксель.

### 3. Антиквариат (Antique)

Каждый новый канал это смесь старых трёх (стандартная формула сепии):

```
R_new = 0.393 * R + 0.769 * G + 0.189 * B
G_new = 0.349 * R + 0.686 * G + 0.168 * B
B_new = 0.272 * R + 0.534 * G + 0.131 * B
```

Сила эффекта регулируется параметром `intensity` (k, от 0 до 1):

```
результат = (1 - k) * исходный + k * сепия
```

При k = 0 изображение не меняется, при k = 1 это полная сепия.

### 4. Выцветание (FadeColor)

Два шага. Яркость Y считается как в п. 2.

Шаг 1. Приближаем цвет к серому (параметр `desaturation`):

```
C1 = Y + (1 - desaturation) * (C - Y)
```

Здесь `C - Y` это «цветная часть» пикселя. Чем больше `desaturation`, тем меньше её остаётся.

Шаг 2. Подмешиваем светлый тон (параметры `alpha` и `level`):

```
C_out = (1 - alpha) * C1 + alpha * level
```

Тёмные места светлеют, контраст падает. Получается выцветшая фотография.

### 5. Имитация плёнки: инфракрасная (FilmEffect)

Шаг 1. Оцениваем яркость в ближнем инфракрасном диапазоне. Растительность в ИК светлая,
поэтому зелёный канал берётся с наибольшим весом:

```
N = clip(0.2 * R + 0.9 * G - 0.1 * B, 0, 255)
```

Шаг 2. Меняем каналы местами, как у цветной ИК-плёнки (листва становится красно-розовой):

```
R_new = N
G_new = R
B_new = G
```

Шаг 3. Увеличиваем контраст относительно середины шкалы (параметр `contrast`):

```
C_new = contrast * (C - 128) + 128
```

Шаг 4. Добавляем зерно: к каждому пикселю прибавляется случайное число (одинаковое для
трёх каналов), в среднем около 0, с разбросом `grain`.

### 6. Matte: овальная белая рамка (Matte)

Для каждого пикселя считаем расстояние до центра. Координаты приводятся к диапазону от -1 до 1,
поэтому форма получается овальной и подстраивается под размер картинки:

```
ny = (y + 0.5 - H / 2) / (H / 2)
nx = (x + 0.5 - W / 2) / (W / 2)
dist = sqrt(ny^2 + nx^2)
```

`dist` равно 0 в центре, 1 на серединах сторон и больше 1 в углах.

Дальше строим маску m, которая равна 0 внутри овала и плавно растёт до 1 за его границей
(параметры `radius` и `feather`):

```
t = clip((dist - radius) / feather, 0, 1)
m = t * t * (3 - 2 * t)
```

Формула `t * t * (3 - 2 * t)` делает переход плавным, без резкой границы.
Итог: где m = 0, остаётся исходный цвет, где m = 1, чистый белый.

```
результат = (1 - m) * исходный + 255 * m
```

### 7. Состаренная фотография (AgedPhoto)

Шаг 1. Применяем сепию (см. п. 3) и уменьшаем контраст с небольшим осветлением:

```
C_new = 0.85 * (C - 128) + 128 + 10
```

Шаг 2. Добавляем шум: к каждому пикселю прибавляется случайное число с разбросом `noise`.

Шаг 3. Рисуем царапины (число задаёт `scratches`). Каждая царапина это тонкая вертикальная линия
случайной длины и положения. На каждой следующей строке линия случайно сдвигается на один пиксель
влево, вправо или остаётся на месте, но сдвиг делится пополам, поэтому линия лишь слегка
изгибается. Цвет царапины чаще светлый (255, вероятность 0.7), иногда тёмный (20).
Прозрачность a случайна от 0.3 до 0.9:

```
результат = (1 - a) * C + a * цвет_царапины
```

Шаг 4. Добавляем пыль (число задаёт `dust`): в случайных пикселях ставятся светлые (255)
или тёмные (15) точки:

```
результат = 0.3 * C + 0.7 * цвет_точки
```

### 8. Неоновый эффект (Neon)

Шаг 1. Считаем яркость Y (п. 2) и слегка сглаживаем её усреднением по соседям (окно 3 на 3),
чтобы убрать мелкий шум.

Шаг 2. Находим контуры оператором Собеля. Он показывает, насколько резко меняется яркость
рядом с пикселем. Для каждого пикселя берутся его 8 соседей с весами:

```
Gx:  -1  0  1        Gy:  -1 -2 -1
     -2  0  2              0  0  0
     -1  0  1              1  2  1

M = sqrt(Gx^2 + Gy^2)
```

`Gx` показывает перепад слева направо, `Gy` сверху вниз, `M` общую силу перепада.
Большое `M` означает контур.

Шаг 3. Приводим силу контуров к диапазону от 0 до 1. Делим на значение, которое превышают
только 1% самых сильных перепадов (так одна яркая точка не делает остальные контуры тусклыми),
затем отбрасываем слабые перепады (параметр `edge_threshold`, t):

```
e = clip(M / P99, 0, 1)
e = clip((e - t) / (1 - t), 0, 1)
```

Шаг 4. Делаем свечение: размываем контуры `e` усреднением по соседям два раза подряд
(радиус `glow_radius`) и усиливаем (параметр `glow_gain`, k):

```
g = clip(3 * k * размытие(размытие(e)), 0, 1)
```

Размытие это среднее по квадрату соседей. Оно считается отдельно по строкам и по столбцам:
для окна из `n` пикселей складываются `n` сдвинутых копий изображения и сумма делится на `n`.

Шаг 5. Собираем результат с цветом линий K (параметр `color`):

```
результат = 0.12 * исходный
          + clip(e + 0.6 * g, 0, 1) * K
          + 0.5 * e^3 * (255 - K)
```

Три слагаемых: затемнённый фон (12% исходной картинки), цветные линии с ореолом
и почти белая сердцевина самых сильных линий. Так линия выглядит как светящаяся трубка.
